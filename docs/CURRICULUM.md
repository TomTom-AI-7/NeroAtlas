# NeuroAtlas カリキュラム設計 / Curriculum Design

対象：東京科学大学 機械系 学部3年。海外大学院で神経工学・精神疾患研究を行い、英語で論文を書く。
到達点（資格ではない）：**公開データでの再現実験 → 独自の研究テーマ → 英語論文草稿**。

時間の指定（毎日10分、Day 1–42 など）は使わない。進捗は「コースのレッスン完了」「理解度チェック」「成果物」で測る。

## 1. 全体構造

```
PREP（基礎・準備）        CORE（必須）                                         ELECTIVE（選択）
P1 脳とニューロン  ─┐     C1 EEG計測 → C2 信号処理 → C3 Python×MNE実データ        E1 BCIハードとリアルタイム
P2 数学とPython    ─┼──▶  C4 機械学習と評価 → C5 精神医学とうつ研究              E2 EEGの深層学習
P3 研究リテラシー  ─┘     C6 研究デザインと統計 → C7 論文読解と再現実験            E3 臨床試験とメタ解析
                          C8 英語科学論文の執筆 → C9 キャップストーン（独自研究）   E4 生物学的精神医学（神経炎症）
                                                                                     E5 計算論的神経科学
                                                                                     E6 統計をRで補強
```

研究成果物パイプライン（アプリの「研究ノート」と連動）：

```
理論ノート → 再現Notebook（PhysioNet MI / OpenNeuro ds003478）→ 先行研究比較表 → 研究ギャップ・仮説
         → 事前分析計画（Methods）→ 図表と限界 → 英語Abstract / IMRaD草稿 → 1ページ研究提案
```

## 2. レッスンの共通型（5ステップ）

1. **Concept** 一次資料に基づく独自要約（日英）
2. **Visual** 図解・インタラクティブなシミュレーション
3. **Practice** 手を動かす演習（Python コード／分析設計／英作文）
4. **Check** 理解度チェック（自動採点、誤答は復習キューへ）
5. **Reflect** 研究メモ・アハ体験・疑問を保存（コース・レッスンに紐づく）

## 4. 研究上の安全柵（全コース共通）
- EEG 単独でうつ病の**原因**（遺伝・睡眠・食事・心理）を特定できると主張しない。予測と因果を区別。
- 診断ラベルと症状尺度を区別する。同一人物のデータを学習とテストに混在させない。
- 人を対象とした計測・介入は倫理審査と同意が必要。公開データは利用条件と引用条件を原典で確認。
- 投稿は、新規性・方法・評価が十分になってから。指導教員との議論を前提にする。

## 5. 拡張方法
- コースは `content/*.js` のデータとして定義。レッスン・クイズ・教材を追加するだけで画面に反映。
- 図解は `js/widgets/` にウィジェットを1ファイル追加し `registry` に登録、レッスンで `visual: { widget: 'id' }` と指定。
- `tests/content.test.mjs` が ID 重複・参照切れ・日英欠落を検出。
