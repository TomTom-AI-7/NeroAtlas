# NeuroAtlas 画面構成 / Screen Design (v2)

参考：fmva-study のワークフロー（開いたらすぐ未回答の1問、解説カード → 問題 → 解説、間隔反復の復習）。

## 毎日の流れ
1. **アプリを開く** → 次の未回答の1問が直接開く（何をやるか選ばない）。
2. **概念の解説カード**（図解が最初）→ 問題。同じ概念の2問目以降は解説が畳まれ、「読む」で開く。
3. 選択肢を**タップした瞬間に採点**。正解と解説が出る。
4. 「ホームに戻る」または「気力があれば、もう一問」。
5. 各概念の最後は**研究課題**（コード実行／英作文など）。保存すると研究ノートと論文草稿に入る。「あとでやる」で飛ばせる。

## 画面（下部タブは3つ・fmva と同じ）
| タブ | 内容 |
|---|---|
| 学習 `#/` | 続きから（1問だけ）・復習ボタン・講座一覧（すべて/プレップ/コア/選択の絞り込みと検索） |
| （講座）`#/course/:id` | 「このコースを続ける」・概念の一覧・目標・成果物・外部教材（公式リンクと利用条件） |
| （演習）`#/practice` | 解説カード → 問題 → 解説 → 次へ。小さな「← 前の問題」で前に習った問題と解説を見返せる（記録は変わらない）。★保存、メモ |
| 復習 `#/review` | 誤答はすぐ、正解は 1・3・7・14・30 日後に再出題。★保存した問題 |
| ノート `#/notes` | メモ／研究課題／論文草稿、書き出し、バックアップと復元 |

## 見た目
白黒。fmva にならい、細い罫線・字間を空けた小見出し・3px の進捗バー・ほぼ平らなカード。
ヘッダーと下部タブは半透明＋ぼかし。色は正解（緑）と不正解（赤）だけ。ダークモード対応。

## 言語切替
日本語と英語の両方を最初から画面に入れておき、ボタンは `<html data-lang>` を切り替えるだけ。CSS がもう一方を隠すので、
画面の再描画・スクロール位置のリセット・入力中の答えの消失は起きない（図のラベルだけその場で描き直す）。

## データ（localStorage `neuroatlas.v2`）
`scores[問題ID] = {attempts, correct, last, streak, due}`、`tasks`、`bookmarks`、`entries`、`draft`。
