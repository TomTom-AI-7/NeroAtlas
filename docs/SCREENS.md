# NeuroAtlas 画面構成 / Screen Design

モバイルファースト（360px〜）。下部タブナビ（スマホ）／左サイドナビ（768px〜）。日英切替は全画面のヘッダーから1タップ。

## ナビゲーション
| タブ | ルート | 役割 |
|---|---|---|
| ホーム | `#/` | 続きから、全体進捗、研究パイプライン、復習キュー |
| コース | `#/courses` `#/courses/:section` | PREP / CORE / ELECTIVE の切替とコースカード |
| （コース詳細） | `#/course/:id` | ロードマップ、目標、成果物、前提・次のコース、教材 |
| （レッスン） | `#/lesson/:courseId/:lessonId` | 5ステップ学習 |
| ノート | `#/notebook` | 研究メモ／アハ／疑問／論文草稿（IMRaD）、エクスポート |
| 教材 | `#/library` | 外部教材一覧（アクセス条件・ライセンス表示、フィルタ） |
| 設定 | `#/settings` | 言語、テーマ、バックアップ（JSON入出力）、リセット |

## レッスン画面の5ステップ
1. 概念：本文（日英）＋キーワード
2. 図解：インタラクティブ図（Canvas/SVG、テーマ対応）
3. 演習：課題文、Python コード（コピー／任意でブラウザ実行：Pyodide）、成果物の書き込み欄 → ノートに保存
4. 確認：選択式クイズ、即時フィードバックと解説、誤答は復習キューへ
5. 振り返り：研究メモ／アハ体験／疑問の3種を保存 → 「レッスン完了」

```
  review: [ { lessonKey, qid } ], entries: [ { id, type: note|aha|question, text, lessonKey, resolved, at } ],
  draft: { title, abstract, introduction, methods, results, discussion, references } }
```
